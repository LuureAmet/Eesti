### **PROMPT #3: Minimaalne Diagnostika & Otsustuspuu**

```
KONTEKST:
- 70a, südamepuudulikkus + AF kahtlus
- NT-proBNP ~1300
- Eelistab minimaalset meditsiini sekkumist
- Tahab teada: MILLAL on ravimid ABSOLUUTSELT vajalikud vs millal saab looduslikult?
- Soov: minimaalsed uuringud; otsus looduslik vs hübriid vs miinimum-meds


EESMÄRK:
Koosta OTSUSTUSPUU:

A) MINIMAALSED UURINGUD (NEED PEAB TEGEMA):
1. Echo - eesmärk: EF% (millal teha, mida küsida), klapid (väljastada numbrid)
2. Holter 24h - eesmärk: AF koormus % (millal teha, mida küsida)
3. Vereanalüüs - eesmärk: ? (millised testid, miks)
- Vere: K, Mg, kreatiniin/eGFR, ferritiin+TSAT, TSH±FT4, hs-CRP, Hb, NT-proBNP


B) OTSUSTUSPUU (IF-THEN):

IF EF% > 40% JA AF koormus < 10% JA turse puudub
→ THEN: Looduslik ravi 6 kuud (täpne protokoll)

IF EF% 30-40% JA AF koormus 10-30% JA kerge turse
→ THEN: Hübriid (looduslik + minimaalne meditsiin - milline?)

IF EF% < 30% VÕI AF koormus > 30% VÕI tugev turse/õhupuudus
→ THEN: Meditsiin vajalik (milline MIINIMUM - diureetik? antikoagulant?)

voi

- IF EF 30–40% VÕI AF% 10–30% VÕI kerge turse → hübriid (nimeta miinimum: nt madal diureetik, antikoagulandi kaalumine CHA₂DS₂-VASc alusel)
- IF EF <30% VÕI AF% >30% VÕI tugev turse/õhupuudus → meditsiini miinimumpakett (nimeta konkreetselt: antikoagulant kui CHA₂DS₂-VASc ≥2; diureetik sümptomile; ülejäänu arsti otsu


C) INSULDIRISK (CHA₂DS₂-VASc):
- Kalkulaator (täida väljad)
- IF skoor ≥2 → Antikoagulant VAJALIK (selgita MIKS looduslik ei asenda)
- IF skoor <2 → Looduslik võimalik (millised taimed toetavad?)

- IF skoor ≥2 (mees) / ≥3 (naine) → trombopreventsioon on vajalik; looduslik ei asenda


D) MILLAL KIIRESTI ARSTI JUURDE:
- Konkreetsed sümptomid (TOP 5)
- Numbrid (pulss, vererõhk, kaal - millised piirid?)

VÄLJUND:
- Otsustuspuu diagramm (tekst-formaat)
- 3 stsenaariumit (parim/keskmine/halvim juhtum)
- Selge sõnum: millal looduslik piisab, millal MITTE
```
