## Praeguse vormi analüüs ja plaan edasi

### 1) Kas praegune vorm on piisav? **JAH + AGA**

✅ **Tugevused:**
- Kõik põhilised ankrud paigas (ajalugu, sümptomid, ravimid, looduslik, aknad)
- Riskiliinid ja koostoimed kaetud
- Otsustuspuu olemas
- Paketivalikud struktureeritud

⚠️ **Puudu / nõrgad kohad:**
1. **Psühhosotsiaalne dimensioon** - puudu sektsioon emotsionaalsest seisust, sotsiaalset tuge, elukriisidest
2. **Kognitiivne profiil** - mälu, tähelepanu (oluline südamepuudulikkuse korral)
3. **Varasemate katsetuste logi** - "mida juba proovisin, mis ei toiminud"
4. **Ootused ja eesmärgid** - konkreetsed 3kuu/6kuu/1a eesmärgid
5. **Digilogi struktuur** puudu - kuhu/kuidas inimene märgib jooksvaid mõõtmisi
6. **"Lisa rida" võimalused** - praegu iga sektsiooni jaoks fikseeritud

### 3) Vormide hierarhia - 3 tasandit

#### **TASE 1: Kiir-AI-prompt (5min)**
```
Minimaalset:
- Vanus, sugu, põhidiagnoos
- Peamine kaebus (1 lause)
- Praegused ravimid (tabel 5 rida)
- Eelistus: □ looduslik □ kombineeritud □ meditsiiniline
- Aeg päevas rutiinideks: ___ min
→ Export: 1-lehe AI prompt
```

#### **TASE 2: Täisprofiil (30min)**
```
Praegune 18-sektsiooniline vorm + lisad:
+ Emotsionaalne seisund (stress, ärevus, depressioon 0-3)
+ Tugivõrgustik (□ elan üksi □ perega □ hooldaja olemas)
+ Varasemate ravide logi (mis ei toiminud)
+ 3 konkreetset eesmärki 6 kuuks
+ Digilogi mall (kuhu märgib päevast kaalu/BP/sümptomeid)
→ Export: JSON + PDF
```

#### **TASE 3: Jooksev logi (päevane/nädala)**
```
Lihtsustatud päevik:
- Kaal (hommik)
- BP (hommik/õhtu)
- Sümptomid 0-3 (õhupuudus, väsimus, turse)
- Rutiin tehtud: ☑︎ hingamine ☑︎ jalutus ☑︎ ravimid
- Märkused (vaba tekst)
→ Export: CSV timeline arstile
```

```

│   KASUTAJA VORM     │ ← Dropdown, checkbox, lihtne keel
└──────────┬──────────┘
           │ export

┌─────────────────────┐

│                     │   + unanswered fields

└─────────────────────┘
```

**Näide:**
- **Kasutaja näeb:** "Kas soovid kaalu vähendada? □ vähe □ mõõdukalt □ palju"

```javascript
// js/form-handler.js

class MedFormHandler {
  constructor() {
    this.profile = this.loadTemplate('base-profile');
    this.sections = {}; // salvestab iga sektsiooni state
  }
  
  // Lisa dünaamiline rida (nt ravimid)
  addRow(sectionId) {
    const section = document.getElementById(sectionId);
    const template = section.dataset.rowTemplate;
    const newRow = this.createRowFromTemplate(template);
    section.appendChild(newRow);
  }
  
  // Kontrolli koostoimeid
  checkInteractions() {
    const herbs = this.getSelectedHerbs();
    const meds = this.getMedications();
    const warnings = [];
    
    herbs.forEach(herb => {
      if (!herb.safety.safe_with_anticoagulant) {
        const hasAnticoag = meds.some(m => 
          ['Xarelto', 'Eliquis', 'Varfariin'].includes(m.name)
        );
        if (hasAnticoag) {
          warnings.push({
            type: 'danger',
            message: `⚠️ ${herb.name_et} + ${meds[0].name} - verejooksu oht!`
          });
        }
      }
    });
    
    this.displayWarnings(warnings);
  }
  
  // Ekspordi JSON
  exportJSON() {
    const data = {
      version: '1.0',
      timestamp: new Date().toISOString(),
      profile: this.profile,
      completeness: this.calculateCompleteness()
    };
    
    this.downloadFile(
      'medform-profile.json',
      JSON.stringify(data, null, 2)
    );
  }
  
  // Ekspordi AI prompt
  exportPrompt(promptNumber) {
    const template = this.loadPromptTemplate(promptNumber);
    const filled = this.fillTemplate(template, this.profile);
    
    this.copyToClipboard(filled);
    alert('✅ Prompt kopeeritud! Kleebi AI-le.');
  }
}

// Kasutus
const formHandler = new MedFormHandler();
document.getElementById('add-medication').onclick = () => {
  formHandler.addRow('medications-section');
};
```
